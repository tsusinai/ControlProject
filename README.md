# ControlProject

一个独立的设计项目管理工作台，用于展示项目、规范进度，并管理里程碑与下一步任务。

## 包含内容

- 展示 rinklnote、gugaproject、海之瞳三个示例项目
- 项目状态、负责人、截止日期、预算、里程碑和进度趋势
- 项目搜索、状态筛选、网格/列表视图
- 调整项目进度、切换项目状态、勾选任务、新建项目
- 鼠标跟随光晕、卡片倾斜、高光、背景网格、漂浮光斑和入场动画
- 移动端响应式布局，并支持减少动态效果偏好

## 本地运行

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```
