# ControlProject

一个独立的设计项目管理工作台，用于展示项目、规范进度，并管理里程碑与下一步任务。

## 包含内容

- 展示 rinklnote、gugaproject、海之瞳三个示例项目
- gugaproject 可进入独立的 Guga 现实事务工作台
- 项目状态、负责人、截止日期、预算、里程碑和进度趋势
- 项目搜索、状态筛选、网格/列表视图
- 调整项目进度、切换项目状态、勾选任务、新建项目
- 鼠标跟随光晕、卡片倾斜、高光、背景网格、漂浮光斑和入场动画
- 移动端响应式布局，并支持减少动态效果偏好

## 本地运行

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```

## Guga 现实事务工作台

gugaproject 不只是总览里的一张卡片。可以用下面任一入口打开独立工作台：

- 侧栏「Guga 工作台」
- 侧栏项目列表里 gugaproject 旁的箭头
- gugaproject 卡片底部的「打开工作台」
- 选中该项目后，详情区的「打开工作台」

在工作台里可以新增、编辑、完成和删除生活事务。每条事务有标题、状态（待办 / 进行中 / 已完成）、优先级，以及可选的下一步和备注。可以按状态、优先级和关键词筛选。

数据保存在当前浏览器的 localStorage，键名是 `guga.affairs.v1`。刷新页面后仍然在。当前是否停在工作台会记在 sessionStorage（`guga.view`），所以刷新后会回到刚才的视图。没有账号，也不会上传到服务器。第一次打开会放进几条示例事务；全部删除后会保持空白，直到你再新建。
